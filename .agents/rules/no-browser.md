# Reglas de Ejecución y Automatización

- **Prohibido el uso de navegador para pruebas**: NO abras instancias de Chrome, pestañas del navegador ni ejecutes el subagente de navegador (`browser_subagent`) para probar, validar o verificar cambios visuales o funcionales, a menos que el usuario lo solicite explícitamente en su mensaje.
- Realiza las modificaciones directamente sobre los archivos del proyecto y reporta los cambios realizados.
